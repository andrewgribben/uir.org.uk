# ÚIR Consulting website

Static website for ÚIR Consulting Ltd. The first draft introduces the parent brand and three service areas: UIR Access, UIR Form and UIR Studio.

## Pages

- `dist/index.html` — company overview and service directory
- `dist/access.html` — UIR Access
- `dist/form.html` — UIR Form
- `dist/studio.html` — UIR Studio
- `dist/pattern-library.html` — shared design system examples

The site is buildless HTML, CSS and JavaScript. Serve `dist/` from a local HTTP server for preview. Site configuration is in `.openai/hosting.json`.

## Design system

Read [`docs/PATTERN_LIBRARY.md`](docs/PATTERN_LIBRARY.md) before changing shared components. The live reference is [the pattern library page](dist/pattern-library.html).
